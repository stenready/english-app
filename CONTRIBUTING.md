# Як долучитися

← [Full-stack App](./README.md)

**Українська** | [English](./CONTRIBUTING.en.md)

Дякую, що хочеш допомогти! Проєкт навчальний і відкритий — раді будь-якому внеску: коду, ревʼю, порадам, тестуванню.

## З чого почати

- **Задачі для старту** — issues з міткою [`good first issue`](https://github.com/stenready/english-app/labels/good%20first%20issue).
- **Ідея чи питання** — створи issue або напиши в [Telegram-чат](https://t.me/stenreadyenglishapp).
- **Ревʼю коду** — коментарі до будь-якого коміту чи pull request'а теж дуже допомагають.

## Запуск

Як запустити всі частини — у [README](./README.md#швидкий-старт).

## Pull request

1. Зроби fork і гілку від `main`.
2. Внеси зміни, дотримуючись [правил проєкту](./admin-panel/README.md#правила).
3. Перевір ту частину, яку змінював:

   ```bash
   npm run typecheck && npm run lint && npm run format:check
   ```

4. Відкрий pull request з коротким описом: що і навіщо змінено.

## Коміти

```
feat(admin-panel): короткий опис
fix(backend-node-app): короткий опис
```

|       | Значення                                                                                     |
| ----- | -------------------------------------------------------------------------------------------- |
| Тип   | `feat` або `fix`                                                                             |
| Scope | `admin-panel`, `client-app`, `backend-node-app` або `root` — для файлів у корені репозиторію |
